# Годовые кольца

Консольное приключение о зимнем лесу, поиске Саши и временных петлях.
Выбирай путь, береги тепло и помогай встречным. У истории три финала.

## Скачать и играть

**[Скачать GodovyeKoltsa.exe](https://github.com/biravijet-ux/godovye-koltsa/releases/latest/download/GodovyeKoltsa.exe)** — готовая игра для Windows. Устанавливать Python не нужно.

1. Скачай `GodovyeKoltsa.exe` по ссылке выше или из раздела Releases и помести в отдельную папку.
2. Дважды нажми на `GodovyeKoltsa.exe`.
3. Вводи номер варианта и нажимай Enter. Ширина окна — желательно от 80 символов.

Папка игры должна быть доступна для записи: сохранение и сюжетные подсказки появятся рядом с EXE.
Игра сохраняется автоматически. `выход` — сохранить и выйти, `и` — рюкзак, `помощь` — управление.
В бою также работают слова `шаг`, `бег`, `камень`, `нож`, `фонарь`, `верёвка`.
Между боями: `съесть сахар`, `согреть птицу`.

Иногда игра закрывается **по сюжету**. Снова открой `GodovyeKoltsa.exe` — история продолжится.
Игра сама создаёт рядом `save.txt`, папку `подсказки` и `.lesdata` с прогрессом.
Не удаляй их во время прохождения. Для переноса сохранений копируй папку игры целиком.

## Запуск исходников

Этот раздел нужен только тем, кто хочет запускать или изменять код.
Нужен Python **3.8+**. У игры нет внешних библиотек, поэтому `requirements.txt` содержит только пояснение.
Открой терминал в папке проекта:

```console
python -m pip install -r requirements.txt
python -X utf8 main.py
```

Для быстрого вывода текста: `python -X utf8 main.py --fast`.

## Сборка EXE на Windows

Проверено с Python 3.11 и PyInstaller 6.21.0:

```console
python -m pip install -r requirements-build.txt
python build_exe.py
```

Готовые EXE с README и ZIP появятся в папке `../releases`.
Другой путь: `python build_exe.py C:\Games\RingsRelease`.
Сборщик не перезаписывает существующие выпуски: выбирай свободную папку.

## Полное описание — СПОЙЛЕРЫ

**Настоятельно рекомендуем читать только ПОСЛЕ прохождения игры.**
Описание раскрывает все акты, временные петли, три финала и устройство проекта.
В игре вместо номера варианта введи десятизначный код:

```text
2411202607
```

Нажимай Enter, чтобы читать по частям. После описания игра вернётся к текущему вопросу.
